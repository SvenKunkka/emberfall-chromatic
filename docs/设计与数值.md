# 《余烬独行》首版设计与数值

版本 1.0 · 核验日期 2026-11-11（Asia/Shanghai）。

## 参考边界

用户要求：像素风、打怪闯关；核心玩法与关卡数值参考微信小游戏《我在废土独自升级》，找不到数据时自行设计。

公开检索找到了同名游戏的榜单与攻略视频线索，但没有取得可核验的官方关卡数值表、技能系数、敌人属性或掉落曲线。因此以下数值全部为本作原创，不能当作参考游戏的数据；美术也没有提取或复用参考游戏素材。

线索：[同名条目列表](https://www.lightgame.cc/game/)、[公开攻略视频线索](https://www.douyin.com/video/7626692164721839375)。这些来源不足以证明本作机制与原作一致。

## 核心循环

进入区域 → 自动寻找最近敌人并发射弹丸 → 移动、冲刺躲避追击和酸弹 → 用范围脉冲解围 → 击杀获得经验并升级 → 完成清怪目标 → 三选一强化并回血 → 下一关。

关卡共用一个开放竞技场布局，切换区域名称、五组地面配色、怪物组合和强度。这是 10 个战斗阶段，不是 10 张不同迷宫地图。第 5、10 关必须同时完成普通怪目标与首领击杀；最后恢复信号并显示结算。

## 玩家与技能

| 项目 | 数值 / 规则 |
| --- | --- |
| 初始生命 / 最大生命 | 60 / 60 |
| 初始攻击 | 8 |
| 初始射击间隔 | 32 次战斗更新 |
| 移动 | 每次更新 1 像素，可以斜向 |
| 冲刺 | A；8 次更新，每次 3 像素；冷却 80 次更新；赋予 20 次更新受击保护 |
| 范围脉冲 | B；曼哈顿距离 <70 像素，攻击 ×3，冷却 240 次更新；清除当前酸弹 |
| 普通受击保护 | 55 次更新 |
| 自动弹丸 | 选择最近目标后以 8 方向发射，每次更新 3 像素，命中消失 |
| 续航 | 每累计击杀 4 个敌人回复 2 HP，封顶 |

“更新”指战斗循环执行一次，不能直接换算成固定 60 FPS 的秒数。VRAM 操作、菜单和模拟器会影响实际耗时。弹丸发出后不追踪，目标运动可以造成落空。

## 经验与强化

- 初始等级 1，首次升级需要 5 XP。
- 爬行者、疾行者每只 1 XP；重装怪、喷吐者每只 2 XP；首领每名 6 XP。
- 每次升级：攻击 +2、最大生命 +5、当前生命 +10（封顶）。
- 升级后，下一级所需经验 = `5 + 当前等级 × 2`；扣除门槛，余数保留。
- 每关选择一项强化，然后回复 20 HP（封顶），进入下一关。

| 强化 | 效果 |
| --- | --- |
| POWER | 攻击 +4 |
| RAPID | 射击间隔 -4，最低 10 次更新 |
| VITAL | 最大生命 +20、护甲 +1；随后应用通关回复 |

护甲从单次伤害中减去自身数值，最低伤害 1。首版没有付费、广告复活、体力、离线收益或跨局成长。

## 敌人差异

| 敌人 | HP | 行为与伤害 |
| --- | --- | --- |
| 爬行者 | 基础 HP | 每 3 次更新追击 1 像素，基础接触伤害 |
| 疾行者 | 基础 HP ×3/4，取整 | 每 2 次更新追击，基础接触伤害 |
| 重装怪 | 基础 HP ×2 | 每 5 次更新追击，接触伤害额外 +3 |
| 喷吐者 | 基础 HP ×3/2，取整 | 保持部分距离，每 90 次更新尝试发射酸弹；接触伤害额外 +3 |
| 守望者 | 第 5 关 180；第 10 关 420 | 追击、周期性闪烁加速冲锋和酸弹；接触伤害额外 +3 |

酸弹伤害 = `6 + 关卡`。普通怪已刷新数量达到本关目标一半时，首领登场。敌方共用一个酸弹槽，避免过密弹幕。

## 美术与工程

16×16 像素角色、8×8 场景图块、主角青绿、普通怪橙红、喷吐者酸绿、首领深红。玩家有方向和步行动画；普通怪为静态像素帧移动。背景有 9 个去重图块与 5 组运行时地面配色。

弹丸仅占一个 8×16 硬件对象；角色通常占两个。运行时按扫描线预算保留完整角色，玩家与首领优先，拥挤时普通怪轮换绘制优先级，弹丸使用剩余容量。该处理不改变命中和生命值。

保留 `.gbsproj`、`.gbsres`、PNG、像素格和项目内战斗场景 C 源码。战斗数值在自定义场景代码中实现，不全部暴露成视觉事件。
